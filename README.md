# Data Structures and Algorithms in Dart

My six-month journey to master Data Structures and Algorithms using Dart.

This repository contains my LeetCode solutions, practice problems, test cases, and learning progress.

## Goals

- Solve approximately 120 LeetCode problems.
- Understand common DSA patterns.
- Write clean and optimized Dart solutions.

## Problem-Solving Method

For every problem:

1. Read and understand the problem.
2. Restate it in my own words.
3. Write 2–3 examples, including an edge case.
4. Explain the brute-force approach and complexity.
5. Identify an optimized approach using a DSA pattern.
6. Implement the solution in Dart.
7. Test the solution on LeetCode.
8. Add 3–5 local test cases.
9. Analyse time and space complexity.
10. Update the progress tracker.
